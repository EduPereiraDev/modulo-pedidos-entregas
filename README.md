# Módulo de Pedidos e Entregas

**Autor:** Eduardo Pereira

## Objetivo

Este repositório reúne a documentação de planejamento do **Módulo de Pedidos e Entregas**, um aplicativo de delivery que cobra taxas diferentes por restaurante parceiro.

O foco é a **EAP (Estrutura Analítica do Projeto)**, que organiza o trabalho em entregas (substantivos) distribuídas em três níveis.
