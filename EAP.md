# EAP — Módulo de Pedidos e Entregas

Estrutura Analítica do Projeto em 3 níveis, organizada por **entregas** (substantivos), não por ações.

```
1 Módulo de Pedidos e Entregas
  1.1 Requisitos
    1.1.1 Lista de requisitos priorizada
    1.1.2 Histórias de usuário
  1.2 Projeto
    1.2.1 Diagrama de classes
    1.2.2 Protótipo das telas no Figma
  1.3 Construção
    1.3.1 API de pedidos
    1.3.2 Telas do aplicativo
  1.4 Entrega
    1.4.1 Plano de testes aprovado
    1.4.2 Pacote de implantação
```

## Observação

O item 1.2.2 aparecia originalmente como "Montar o protótipo no Figma", que descreve uma **ação**. Na EAP ele foi reescrito como a **entrega** "Protótipo das telas no Figma".
